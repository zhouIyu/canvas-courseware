# Canvas Courseware VNext Plan

本文档用于记录下一版本的规划、范围边界和开发批次，不直接替代当前执行中的 `docs/TODO.md`。

## 版本定位

- 当前版本切换为 `VNext-34`，围绕 2026-04-29 新增需求推进下一轮工作。
- 版本目标聚焦三个方向：编辑态拖拽稳定性、slide 页面管理入口集中化、预览态布局与信息架构收敛。
- 本轮规划已同步进入 `docs/TODO.md`，后续以 `docs/TODO.md` 作为实际执行与状态跟踪的唯一事实来源。

## 已确认范围

- [x] VNext-34-A 编辑态拖拽稳定性优化
  说明：
  围绕 2026-04-29 的拖拽稳定性反馈，排查并优化编辑态元素拖动时的抖动与回跳问题。
  来源：
  2026-04-29 用户新增需求
  需求拆分：
  1. 编辑态拖拽 `Text / Image / Rect` 时，不再出现明显抖动、回跳或位置反复震荡。
  2. 拖拽经过吸附阈值区域时，位置反馈保持连续，不因吸附判断滞后一帧而出现来回跳动。
  3. 拖拽释放后，自动保存与刷新恢复结果保持正确。

- [ ] VNext-34-B slide 卡片交互与右键菜单
  说明：
  优化左侧 slide 卡片交互体验，并新增卡片级右键菜单，把常用页面管理入口收敛到当前操作上下文。
  来源：
  2026-04-29 用户新增需求
  需求拆分：
  1. slide 卡片 hover、选中与右键呼出反馈更明确，页面管理入口更集中。
  2. 右键菜单中展示“后插入”“复制”“删除”三个常用操作。
  3. “删除”操作需带弹窗二次确认，并保持现有拖拽排序链路不受影响。

- [ ] VNext-34-C 预览页布局与信息架构联合优化
  说明：
  把预览态相关布局与信息问题作为同一轮工作统一处理，释放中心课件区域空间并收敛非核心信息。
  来源：
  2026-04-29 用户新增需求
  需求拆分：
  1. 压缩预览态 slide 卡片高度与纵向占比，避免列表继续吃掉主预览区空间。
  2. 提升中心课件区域的可用高度，保证常见桌面视口下课件画面更完整。
  3. 中心区域只保留课件本身，把步骤说明或辅助信息移出主预览区。

## 暂不纳入下一版本

- 富文本与复杂排版系统
- 协同编辑与远程项目存储

- 模板市场与模板管理
- 多引擎同时接入

## 约束说明

- 下一版本仍需遵守 `docs/PRD.md` 中定义的架构边界，尤其保持 UI 层与事件层解耦、文档模型与渲染引擎解耦。
- 拖拽稳定性修复、slide 卡片右键菜单与预览态布局调整都必须通过标准命令层与状态层落地，不得直接把 Fabric 事件逻辑耦合进 Vue 组件。
- 预览态优化仍需保持“课件区域优先”，不能为了压缩信息而引入额外播放态私有数据结构。
- 当前版本规划已同步进入 `docs/TODO.md`，因此相关需求不再保留在 `docs/REQUIREMENTS.md` 中重复记录。
